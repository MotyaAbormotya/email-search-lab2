# Лабораторная работа № 2. Проверка и поиск e-mail

Консольная программа проверяет один адрес или ищет адреса в тексте,
UTF-8-файле и на веб-странице.

## Запуск

Нужен Python 3.10 или новее. Из папки проекта выполни:

```text
python main.py
```

## Слои проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | Создаёт хранилище и сервис, запускает меню |
| `presentation/console.py` | Меню, ввод, вывод и сообщения об ошибках |
| `application/email_service.py` | Поиск адресов, удаление повторов и вызов хранилища |
| `domain/email.py` | Регулярные выражения и проверка адреса |
| `domain/repository.py` | Контракт для чтения источников и записи результата |
| `infrastructure/text_repository.py` | Чтение файлов и страниц, запись результата |
| `test_main.py` | Тесты на `unittest` |

Консоль вызывает `EmailService`. Сервис работает с интерфейсом
`TextRepository`, а чтение файла и HTTP-запросы выполняет
`FileAndWebRepository`. Для поиска в тексте сервис получает готовую строку.

## Пример работы

1. Выбери `1` и введи `name+lab@example.org`. Адрес пройдёт проверку.
2. Выбери `2` и введи `Почта: name@EXAMPLE.org, name@example.org`.
   Программа выведет один адрес `name@example.org`.
3. Через пункт `3` можно открыть текстовый файл, а через пункт `4`
   указать адрес страницы с `http://` или `https://`.
4. После поиска введи `д`, если хочешь сохранить результаты, и укажи имя
   файла, например `emails.txt`.

## Правила проверки

Поддерживаются адреса из ASCII-символов вида `имя@домен`. В части до
`@` нельзя ставить точки в начале, в конце или подряд. В домене нужно
хотя бы две части, разделённые точкой. Дефис допустим внутри части домена,
а последняя часть должна состоять из 2–63 латинских букв.

Проверяется синтаксис. Адреса с кавычками вокруг имени, домены в виде
IP-адресов и Unicode-адреса в этот вариант проверки не входят.
При поиске домен приводится к нижнему регистру, регистр имени сохраняется.
Повторы убираются в порядке первого появления. Для URL читается не больше
1 000 000 байт ответа.

## Тесты

```text
python -m unittest -v
```

Тесты проверяют корректные и некорректные адреса, длину частей, поиск
в тексте и удаление повторов.
